## Bilan

On a explicité le terme **refactorisation**: on change le code, mais le comportement du programme (la fonctionnalité) est identique.

On a maintenant fait trois étapes du drone console:
- Créer un, puis deux ou trois drones sur la base des acquis de la 1ère année avec des variables simples
- Refactorisé le code pour utiliser plusieurs tableaux pour avoir plusieurs drones
- Refactorisé le code pour grouper dans une classe tous les attributs et comportements d'un drone
